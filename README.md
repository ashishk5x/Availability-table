# 📅 Availability Table

A clean and responsive availability table built using **HTML5** and **CSS3**. The project visually represents weekly availability using a color-coded schedule and CSS custom properties (variables). It was created as part of the **freeCodeCamp Responsive Web Design Certification**.

## 🚀 Features

- 📅 Weekly availability schedule
- 🎨 Color-coded availability levels (0–5)
- 🌈 CSS Variables for reusable colors
- 📊 HTML table layout with semantic elements
- 📏 Alternating solid and dashed row borders
- 🎯 Linear gradient legend with hard color transitions
- 📱 Clean and modern layout
- ♿ Semantic HTML structure
